### 🧑‍💻 About Me

I'm a Full-Stack (MERN) Developer who also builds data pipelines. I have a B.Tech in Information Technology, hands-on experience shipping full-stack web applications with React, Node.js, Express, and MongoDB, and production-style data engineering experience with PySpark, Delta Lake, and Databricks on GCP.

On the web dev side, I like building things people actually use — clean auth flows, APIs that don't fall over, UIs that feel fast. On the data side, I like tracing why a join produces duplicate rows or deciding how a pipeline should behave when the same record arrives twice. Different problems, same instinct: build things that quietly work, every time.

- 🔭 **Currently building:** Deepening my MERN project portfolio, alongside a retail sales ELT pipeline (Bronze-Silver-Gold) on Databricks
- 🌱 **Currently sharpening:** DSA/JS fundamentals + system design basics for web dev interviews; Airflow orchestration for data pipelines
- 💬 **Ask me about:** React, Node.js, Express, MongoDB, REST APIs — or PySpark, Delta Lake, Spark SQL
- 📫 **Reach me:** [vivekkumar.contacts@gmail.com](mailto:vivekkumar.contacts@gmail.com)
